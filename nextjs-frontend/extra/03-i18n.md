# Extra 03 · i18n

WHEN: the UI ships more than one language (or must, legally).
LOAD: this file **and** 01, 06, 10, 11.
SCOPE: where strings live. MUST NOT: `ui/` with English baked in (11). MUST NOT: i18n "because we might."

---

## Where strings go

MUST: user-visible copy in message files (`messages/en.json` or the project's next-intl/lingui layout), keyed by feature (`orders.cancel`, not `btn1`).

`ui/` primitives take labels as props. Features pass translated strings.

MUST: `lang` on `<html>` matches the active locale (15). MUST: locale in the URL (`/en/orders`) **or** a cookie the product already chose — pick one and stay. MUST NOT: locale only in `localStorage` (shareable links die).

Dates/numbers: `Intl`. MUST NOT: hand-rolled `DD/MM`.

MUST NOT: translate `error_code`. Translate nothing from the API if `message` is already the product language (backend 12). If the API is English-only, map `error_code` → a message key in this Extra.
