# 11 · UI primitives and tokens

WHEN: a Button, field, modal, skeleton, empty, overlay, icon, motion, or a colour/spacing token.
LOAD: this file. Visual rules: [01-design.md](01-design.md) first.
RELATED: 03 (`ui/` vs `features/`) · 05 (`"use client"` on primitives that take events) · 15 (name, focus) — open only if the task is also that topic.
SCOPE: `frontend/ui/` and `app/globals.css` (or `styles/tokens.css`). No product noun.

`ui/` is the kit. Features pass copy and data. If deleting the product would still leave this file, it belongs here.

---

## Tokens

MUST: colour, radius, space, type, z-index, shadow as CSS variables (or the project's token layer). Hex, raw `px`, and `rgba` only in that file (01).

Day-one names (rename in this file if the project already has a kit — then write the names here):

- Colour: `--surface`, `--surface-muted`, `--text`, `--text-muted`, `--border`, `--accent`, `--danger`, `--success`, `--warning`, `--focus`
- Space: `--space-1` … matching the 4/8px scale (01)
- Type: `--font-sans`, `--font-mono`, `--text-body`, `--text-title`, `--leading-body`
- Radius: `--radius` (one). `--radius-full` only for avatars/chips that are meant to be pills
- Elevation: `--shadow` one step, or none. MUST NOT: a shadow scale of six
- Overlay: `--z-dropdown`, `--z-modal`, `--z-toast` — three numbers, increasing. MUST NOT: `z-[9999]` in a feature

Components use token names (`bg-surface`, `text-muted`, `border-border`). MUST NOT: `bg-[#7C3AED]`. MUST NOT: a third radius on one screen.

Dark: only if the product ships it. Then the **same names** swap values under `[data-theme="dark"]` (or `prefers-color-scheme` if that is the product rule). MUST NOT: a second component set (`ButtonDark`). MUST NOT: invert by CSS `filter` on the whole app.

## What is a primitive

Stop at the first yes.

1. Would this still exist if the product had zero nouns (no orders, no auth)?
   → `ui/`
2. Does the filename contain a product noun?
   → **not ui** — `features/<noun>/` (10)

Open when first used, not as a kit dump:

- `Button` — `primary` | `secondary` | `danger` | `ghost`. One visual primary (01). `type="button"` default; forms pass `type="submit"`.
- `TextField` / `Select` / `TextArea` / `Checkbox` — visible label, error slot, `describedby` when there is help/error (15).
- `Skeleton` — layout-shaped, not a circle in a void (01).
- `Empty` — title + optional action **as children/props**. No baked English.
- `Banner` — `info` | `danger` | `success`. Icon + text. MUST NOT: left rainbow stripe as the only language (01).
- `Modal` / `Drawer` — focus trap, Escape, return focus, labelled title (15). MUST NOT: a modal without a close.
- `Toast` — one host in the root layout. Features call a tiny `toast()` in `lib/` or a client leaf. MUST NOT: a toast per feature.
- `Spinner` — short in-place wait only. Page load is `Skeleton` (01, 07).

MUST NOT: `ui/OrderCard`, `ui/Dashboard`, `ui/UserAvatarMenu` as the home of product markup. A generic `Avatar` that takes `src` + `name` is allowed.

MUST NOT: `ui/Table` that knows columns of orders. A layout primitive (`Stack`, `Divider`) is allowed if it has no noun.

Icons: one set. Decorative icons `aria-hidden`. Icon-only control: accessible name (15). MUST NOT: emoji as the system. MUST NOT: a different icon pack per feature.

---

## Motion

MUST: short (`150–200ms`), opacity/transform only, `prefers-reduced-motion: reduce` disables. MUST NOT: bounce on every list row. MUST NOT: autoplay decorative Lottie on a form.

---

## Composition

A feature builds screens from primitives + its own panels. MUST NOT: a primitive import `features/`. MUST NOT: `ui/` import `lib/api.ts`.

`"use client"` on the primitive that has `onClick` / `onChange`, not on every file in `ui/` (05). A server page may still render `Button` if the button is a link (`<a>` / `Link`) with styles — prefer `ui/LinkButton` without client JS when there is no handler.

---

## Four states

Empty / skeleton / banner are **slots**. The feature passes title, body, action (01). MUST NOT: `Empty` that says "No orders yet" inside `ui/`.
